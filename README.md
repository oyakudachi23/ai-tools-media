# AIツール比較メディア（MVP）

GitHub Pagesで公開できる、HTML/CSS/JavaScriptのみで作成した静的サイトです。

## 編集ポイント
- ツール追加・更新: `data/tools.csv`
- 見た目調整: `assets/css/style.css`
- 表示ロジック: `assets/js/main.js`

## GitHub Pages公開手順
1. このリポジトリをGitHubへpush
2. GitHubの `Settings` → `Pages`
3. `Source` を `Deploy from a branch` に設定
4. Branchを `main`（または利用ブランチ）/ `/ (root)` に設定
5. 数分待って発行されたURLへアクセス
